# 📘 README – Projeto NotebookLM: HKS 3.0

## Visão Geral
Este repositório documenta a criação de um **caderno temático no NotebookLM** sobre o **novo HKS 3.0**, reunindo fontes abertas em texto e PDF. O projeto explora como a IA pode apoiar o aprendizado ativo, organizando informações, elaborando perguntas estratégicas e consolidando conhecimento em um **miniguia de estudo**.

## Objetivos
- **Compreender** os principais conceitos e atualizações do HKS 3.0.  
- **Praticar** curadoria de fontes abertas e confiáveis.  
- **Aplicar** prompting estratégico para extrair e organizar informações.  
- **Consolidar** resumos, glossário e prompts reutilizáveis para futuras revisões.

🚀 Guia Rápido de Uso – Projeto HKS 3.0 no NotebookLM
1. Acesse o NotebookLM
>Entre no NotebookLM by Google e crie um novo caderno temático dedicado ao HKS 3.0.

2. Carregue as Fontes
>Utilize os materiais listados em docs/fontes.md (PDFs, artigos técnicos, guias práticos).

>Essas fontes serão a base de conhecimento para o estudo do HKS 3.0.

>Certifique-se de que todas as fontes são abertas ou possuem licença adequada.

3. Use os Prompts
>Aplique os prompts estratégicos documentados em docs/prompts.md.

Exemplos:

“Explique as principais diferenças entre HKS 2.0 e 3.0 em linguagem simples.”

“Liste 5 aplicações práticas do HKS 3.0 em cenários reais.”

>Teste variações de estilo (explicação, comparação, checklist) para extrair diferentes perspectivas.

4. Siga o Guia de Estudos
>Consulte docs/miniguia.md para uma jornada de aprendizado estruturada.

>O guia organiza os tópicos em ordem lógica: histórico, novidades da versão 3.0, aplicações práticas e impacto esperado.

>Use o docs/glossario.md para revisar termos técnicos e conceitos essenciais.

5. Gere Podcast
>Explore a funcionalidade de podcast automático do NotebookLM.

>Transforme os resumos e insights em episódios curtos para revisão auditiva.

>Ideal para reforçar o aprendizado em momentos de deslocamento ou pausas rápidas.
